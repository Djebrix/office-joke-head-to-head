One short line about office life, judged head-to-head by a judge model — entry for [The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c).

## The line

> The lift's been broken for six months, so HR rebranded the stairwell as a wellness programme.

## Run

```sh
python3 main.py
```

Writes the line to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Stdlib only, no network, deterministic — two runs produce byte-identical output.
